Employee Todo List
===================

A small React app for managing an employee list, with add, edit, and delete functionality. Built with Create React App.

Tech stack: React 19, Create React App, Jest and Testing Library for tests.

Project structure follows the standard CRA layout: static assets live in public, application source lives in src (App, EmployeeTable component, styles, and tests).

Getting started: run `npm install` followed by `npm start` to launch the dev server at http://localhost:3000. Run `npm test` to run the test suite, or `npm run build` for a production build.
